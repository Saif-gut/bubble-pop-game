# Bubble Pop Game

Ein Roblox-Spielprojekt, in dem Spielende Bubbles platzen lassen und Fortschritt über Spielgeld, Ausrüstung, Pets, Bereiche und Upgrades sammeln sollen.

## Projektstand

Dieses Repository enthält den aktuell vorhandenen Roblox-Studio-Place als `Place1.rbxl`. Das Spiel befindet sich in Entwicklung; eine vollständige Spielversion oder fertige Features werden hier bewusst nicht behauptet.

## Öffnen

1. Roblox Studio öffnen.
2. `Place1.rbxl` über **File → Open from File** laden.
3. Das Spiel im Studio testen oder weiterentwickeln.

## Hinweise

- `Place1.rbxl` ist die vorhandene Projektquelle und wird versioniert.
- Lokale Sicherungs-, Auto-Save- und Editor-Dateien sind über `.gitignore` ausgeschlossen.
- Es sind keine Projekt-Screenshots im Quellordner vorhanden.
